# 開発ノート 0.2.0-dev（ソース実装、APK未生成）

## 今回追加

- 通知設定・次回予定・履歴・テスト通知。「その他」から全体設定、懸賞詳細から個別設定。
- 確認済み締切・周期から7日分を永続化し、OSへ次回1件を予約。
- 標準／時刻優先、通知権限・チャンネル・省電力状態の診断、おやすみ時間。

- 応募済み・期限超過の抑止、投稿失敗の同一ID再試行、理由の90日履歴。
- DB v1→v2 migration。取込由来の推定周期は再確認が必要。

通知許可は「通知を許可」を押した時だけ要求する。時刻優先は設定を保存してから特別アクセスを設定する。通知は端末制限により遅れたり届かない場合がある。
